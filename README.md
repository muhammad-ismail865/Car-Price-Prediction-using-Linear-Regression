# Car Price Prediction using Linear Regression

A Machine Learning-based Car Price Prediction system built using **Python** and **Scikit-learn**.
This project predicts car prices based on various features such as car brand, model, transmission type, fuel type, engine size, mileage, and manufacturing year using a **Linear Regression** model.

# 📌 Project Overview

Car price prediction is an important real-world machine learning application that helps estimate the market value of vehicles based on their specifications.

This project demonstrates the complete machine learning workflow:

* ✅ Data preprocessing
* ✅ Label Encoding for categorical features
* ✅ Feature scaling using StandardScaler
* ✅ Train-test data splitting
* ✅ Linear Regression model training
* ✅ Model evaluation using regression metrics

# 🚀 Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn

# 📂 Features Used

The model uses the following features for prediction:

| Feature      | Description                    |
| ------------ | ------------------------------ |
| Make         | Car company/brand              |
| Model        | Car model                      |
| Transmission | Manual or Automatic            |
| Fuel Type    | Petrol, Diesel, Electric, etc. |
| Year         | Manufacturing year             |
| Engine Size  | Engine capacity                |
| Mileage      | Distance covered               |
